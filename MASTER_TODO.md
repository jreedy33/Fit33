### 0.2 Notes

- `Color.cardGradientStops(for:)` documents the chosen light-mode stops as `[.white, .white.opacity(0.95)]` to preserve pre-Sprint-9 behavior bit-for-bit; do NOT change these without snapshotting the affected screens — several cards rely on the white→near-white gradient to fake a subtle highlight in light mode.
- The admin MFA enrollment flow intentionally does NOT set auth cookies between "password verified" and "TOTP verified". Any future "remember this device" feature must keep that invariant — the temp access token is held client-side in memory only during the enrollment modal.
- `SupabaseDTOs.swift`'s policy header codifies the rule for future DTOs: if the DTO maps a row (1:1 with a table), decode fields as they are in the DB; if the DTO maps an aggregation (RPC `RETURNS TABLE` with COUNT/AVG/SUM), write a custom `init(from:)` that defaults numeric `NULL`s to zero.
